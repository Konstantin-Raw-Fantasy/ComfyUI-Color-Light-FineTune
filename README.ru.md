# 🎨 Color-Light-FineTune

Узел для цветовой и световой коррекции в ComfyUI: встроенный live-превью, цветовые колёса, позонная цветная балансировка, тональные кривые, киноплёночное зерно и точечные правки (выбранный цвет). Работает с картинками и видео (батчами кадров).

![Узел Color-Light-FineTune](Node-screenshot.jpg)

## Возможности

- **Live-превью внутри узла** — обновляется в реальном времени при перетаскивании регуляторов, без Queue
- **Цветовые колёса** — LIFT (тени) / GAMMA (средние тона) / GAIN (блики) / OFFSET (весь диапазон): полный круговой диск оттенков, ползунок интенсивности (LEV) у каждого колеса, живой RGB-вывод
- **Adjust Picked (выбранный цвет)** — клик по цвету на превью, правится только этот цвет: допуск / оттенок / насыщенность / яркость; слайдеры серые, пока цвет не выбран
- **Позонная цветная балансировка** — температура + насыщенность для Теней / Средних тонов / Бликов / Белого (8 слайдеров под превью)
- **Тональные инструменты** — Brightness, Contrast, трёхточечная тональная кривая, Vibrance
- **Highlight Ceiling / Shadow Floor** — мягкое плечо и подошва: пересветы плавно уходят в белый вместо клипа, чёрная точка приподнимается с сохранением текстуры теней
- **Киноплёночное зерно** — встроенный пресет со шкалами Strength / Size / Softness; детерминировано (один и тот же кадр всегда получает одно и то же зерно, без мерцания)
- **Поддержка видео** — frame slider под превью для перемотки; прогресс обработки выводится в терминал ComfyUI каждые 16 кадров (рендер на CPU)

## Установка

1. Скопируйте эту папку в `ComfyUI/custom_nodes/`
2. Перезапустите ComfyUI

**Требования**

- Нет дополнительных пакетов — используется только torch (и PIL/aiohttp, уже входящие в состав ComfyUI)

## Использование

- Подключите картинку (или видео → батч кадров). AUDIO — необязательный passthrough для видео.
- Все регуляторы по умолчанию нейтральны → идентичный вывод.
- Финальный результат, как обычно, выдаёт **Queue**.
- **Выбор цвета:** клик по превью (точка отмечается перекрестием) → слайдеры ADJUST PICKED становятся активными.
- **Примеры воркфлоу:** [картинка](examples/Image_Color-Light-FineTune.json) · [видео](examples/Video_Color-Light-FineTune.json)
